# Industrial Hydraulic Press Simulator

A technical 3D prototype created with Unity, C# and Blender.

## Overview

The Industrial Hydraulic Press Simulator is a small interactive 3D application that demonstrates how Unity can be used for technical and industrial visualization.

The hydraulic press was modeled in Blender and imported into Unity as separate machine components. C# is used to control interactions, machine behaviour and the visual response of the application.

## Technologies

- Unity
- C#
- Blender
- Git / GitHub

## Focus

- Technical 3D visualization
- Object-oriented C# development
- Interactive machine components
- UI and user feedback
- Blender-to-Unity workflow
- Structured separation of machine logic and visual behaviour

## Project Goal

The project was created to explore the use of real-time 3D technologies outside traditional game development.

The focus is on combining technical visualization with interactive software behaviour.
